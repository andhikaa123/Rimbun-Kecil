# Rimbun Kecil - Toko Tanaman Hias

Jalankan dengan XAMPP/Laragon: letakkan folder ini di `htdocs`, lalu buka `http://localhost/rimbun-kecil/`.
Atau dengan terminal: `php -S localhost:8000` di dalam folder ini.

Struktur:
- includes/  : data.php, fungsi.php, header.php, footer.php, kartu_produk.php
- assets/    : css/style.css, js/app.js
- Halaman    : index, katalog, produk, keranjang, checkout, pesanan, perawatan, kontak
- Akun       : login, daftar, logout, akun (data di folder data/ berformat JSON)
